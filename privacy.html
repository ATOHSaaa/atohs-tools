本ページは tools.atohs.me（以下「本サイト」）における情報の取り扱いを説明します。ツールによって外部連携や保存の有無は異なります。共通事項は本ページに、個別の事情は該当する節または各ツールページに記載します。

本サイトについて

本サイトは個人（atohs）が運営する Web ツールの集です。掲載ツールの名称や利用する外部サービスに含まれる商標・ロゴ等は、それぞれの権利者に帰属します。任意のタイミングで、ツールの追加・変更・公開終了を行う場合があります。

入力内容とサーバー

各ツールで入力・編集したテキストは、原則としてあなたのブラウザ内だけで処理され、本サイトの運営者が用意したアプリケーションサーバーへ送信されることはありません（静的サイトとして配信しています）。 ホスティング事業者（GitHub Pages 等）のアクセスログが別途残る場合があります。

ブラウザ内の保存

サイト全体の表示設定（例: ダークモード、キー atohs-theme）や、各ツールの作業状態は、必要に応じて localStorage 等に保存することがあります。保存する項目はツールごとに異なり、ブラウザのデータ削除や設定変更で消えることがあります。

Font Simulator と Google Fonts

Font Simulator を利用する場合、プレビュー用のフォントファイルおよびスタイルシートを fonts.googleapis.com・fonts.gstatic.com から取得します。フォント一覧の取得には Fontsource API を利用する場合があります。表示フォントのライセンスは Google Fonts 上の各フォントに従い、本サイトはフォントファイルの販売や再配布を行いません。

上記の読み込みのため、ブラウザが Google のサーバーへ接続する際、接続元 IP アドレスなどが Google に送信される可能性があります（Google のプライバシーポリシーが適用されます）。欧州など一部の法域では、同意なしのフォント読込みが問題視された事例もあるため、国外から利用される場合はご留意ください。詳細は Google のプライバシーをご確認ください。

アクセス解析（Google Analytics 4）

本サイトでは、利用状況の把握のため Google Analytics 4（GA4） を利用します。Cookie 等を用いて、ページの閲覧、端末・ブラウザの種類、おおよその地域、参照元などが Google に送信されることがあります。

  • 提供者: Google LLC
  • 概要: Google プライバシーポリシー、 Google Analytics 利用規約
  • オプトアウト: Google Analytics オプトアウト アドオン、ブラウザの Cookie 設定

セッション記録（Microsoft Clarity）

本サイトでは、UI 改善のため Microsoft Clarity を利用する（または利用する予定です）。ページ上の操作、スクロール、クリックの集計や、セッション記録（ヒートマップ等）が Microsoft に送信・保存されることがあります。入力フィールドに個人情報や機密情報を入れた場合、それが記録に含まれる可能性があるため、ご注意ください。

  • 提供者: Microsoft Corporation
  • 概要: Microsoft プライバシー、 Clarity 利用規約

お問い合わせ

本ポリシーに関するお問い合わせは、サイト運営者（atohs）までご連絡ください。連絡先は atohs.me をご覧ください。

変更
