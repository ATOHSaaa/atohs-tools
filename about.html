tools.atohs.me について

tools.atohs.me は、日常で「ちょっと欲しい」と思った処理をブラウザだけで済ませるための Web ツールの集です。

方針

  • フロントのみ。静的ホスティング（GitHub Pages）で配信
  • HTML / CSS / JavaScript。依存は必要最小限
  • 外部サービスや解析の利用は プライバシーポリシーにまとめる

運営

制作・運営は atohs（あとーす）。見た目やテーマは atohs.me に合わせています。tadeku-tools とは別プロジェクトです。
